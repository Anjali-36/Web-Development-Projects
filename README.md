# Web-Development-Projects 🚀

A collection of interactive web development projects built using **HTML, CSS, and JavaScript**.  
This repository showcases frontend development skills including responsive design, DOM manipulation, event handling, and interactive UI development.

---

## 📌 Projects Included

### 🎮 Rock Paper Scissors
A fun interactive game where users play against the computer with sound effects and score tracking.

**Features:**
- User vs Computer gameplay
- Scoreboard system
- Sound effects
- Interactive UI

---

### ⏱️ Stop Watch
A functional stopwatch application with start, stop, and reset functionality.

**Features:**
- Start timer
- Stop timer
- Reset timer
- Responsive design

---

### ❌⭕ Tic Tac Toe
A two-player Tic Tac Toe game built with JavaScript.

**Features:**
- Player turn switching
- Winner detection
- Restart game option
- Interactive gameplay

---

### 🌦️ Weather Report
A weather application that displays weather information dynamically.

**Features:**
- Search weather by city
- Dynamic weather updates
- User-friendly interface

---

## 🛠️ Technologies Used

- **JavaScript (ES6)**
